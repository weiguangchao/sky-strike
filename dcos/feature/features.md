# 功能清单

## 机库与界面

- 机库展示所选章节允许使用的两到三架战机、二维精灵预览，以及火力／机动／装甲。
- 页首使用「破晓出击」像素飞机 Logo，提供透明底 SVG／PNG、单色版和独立简化网页图标；见[品牌 Logo](logo.md)。
- 战场与机库模型采用低分辨率像素渲染，中英文界面均使用本地像素字体：Fusion Pixel负责中文与一般文字，原创矢量像素字标负责页首品牌，VT323负责仪表；保留海军蓝／橄榄绿主题、琥珀黄按钮与清晰战斗识别图例。中文WOFF2随入口样式同源加载，完整字库涵盖历史舰名；字体加载失败仍可使用系统字体继续操作。
- 界面采用「柔和仪表」圆角样式，统一按钮、模式／战机切换、徽标、键帽、强化卡、机库框和手册；保留像素战机与战斗标记的清晰轮廓。
- 「游戏模式」提供战役与无尽。桌面在任务侧栏切换模式并打开章节选择；手机和较小窗口从战场标题栏的「游戏模式」打开选择。战役标记已通关和未解锁关卡，无尽只选择起始章节。
- 精简重复宣传句、英文副标题、机型编号、坐标与状态小字；主要按钮、战机名称和强化名称使用大字，普通手机窗口的强化效果说明至少 14px。
- 手机机库保留品牌、手册与紧凑战机选择栏；开战后自动切换沉浸布局，隐藏品牌栏、航区标题、选择栏和外框留白。暂停、强化和结算期间保持同一战场尺寸，返回机库后恢复导航。
- 开战后锁定战机与模式；暂停可重开或返回机库。战役结算在解锁下一关后提供「下一战役」。
- 战斗 HUD 显示积分、波次、装甲、等级、能量进度、自动对舰状态和剩余手动航弹；护航时在底部显示友军装甲。
- 战斗计分栏背景向下渐隐，波次提示采用两侧渐隐的半透明横幅，保证窗口缩小后顶部敌弹和玩家战机仍可见。
- 首领战显示首领名称、剩余时间、装甲条、剩余百分比以及左炮／右炮／舰桥／甲板状态。
- 波次、航区切换、补给与首领击破有短暂提示；强化面板展示三个选项、效果与叠加等级。
- 桌面侧栏显示本局已获得的强化。
- 机库和手册提供战场识别图例，战斗底部显示「机炮对空 · 自动对舰」与手动航弹数量，护航期间显示运输船装甲。道具通过颜色、外框和中心符号共同区分，避免和敌弹混淆。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD、方向键、按住鼠标拖动 | 在战场按住拖动 |
| 自动机炮对空 | 战斗期间自动执行 | 战斗期间自动执行 |
| 自动投弹对舰 | 横向对准舰体／部件，无需额外按键 | 横向对准舰体／部件，无需额外按键 |
| 高爆航弹 | 空格、B、右下角按钮 | 右下角按钮 |
| 暂停／继续 | P、Esc、暂停按钮 | 暂停按钮／继续作战 |
| 强化选择 | 点击卡片、数字键 1／2／3 | 点击卡片 |
| 声音开关 | M、顶部声音按钮 | 顶部声音按钮 |
| 全屏 | 顶部全屏按钮，需浏览器支持 | 顶部全屏按钮，需浏览器支持 |

拖动采用相对位移，按下时不会把战机瞬移到指针位置。鼠标从战场开始拖动后，经过投弹按钮仍连续移动。触摸拖动经过按钮后返回战场仍可继续，抬手或取消后停止；单独点击投弹按钮仍投弹。对角线键盘移动会归一化，保持与单方向相同的速度。

进入战斗、窗口和可视区域变化后，输入比例按当前画布尺寸刷新；连续拖动经过投弹按钮后返回战场仍可移动，抬手或取消触摸时结束该手势。

## 暂停与作战手册

- 手动暂停时冻结战斗，支持继续、重开、返回机库。
- 页面进入后台或窗口失焦时自动暂停，并清除持续按键和拖动状态。
- 升级三选一时自动冻结战斗，完成选择后继续，并给予短暂保护。
- 打开作战手册会暂停正在进行的战斗；关闭手册后恢复该场战斗。
- 手册提供「操作／战役／图鉴」三个页签；操作说明自动对空、对准舰船投弹、手动清弹与白点判定。图鉴仅保留上述八国，汇总当前126条舰艇外观、18型飞机与18级潜艇，共162条，可按国家、类别和年代筛选、按需查看本地二维精灵。八国服役目录仍在核对，尚未全部收齐；先Grok总评及逐项≥9.8，再由GPT Sol／Claude Opus独立评审，三方总评及逐项均≥9.8才计为通过，未评审模型保持草稿状态。规则见[百年舰机](century-archive.md)。
- 图鉴首行显示原型国家和服役时间，直接显示年份或史料状态，页码靠右。第二行显示类别和适用的服役时间口径，舰船优先显示有依据的舰级。名称和「史料 ↗」同排，下面显示结构说明与已核实的多国服役信息。卡片放得下时，结构说明按「·」拆成带分隔线的逐条列表并延伸到预览框底边，各条目字号一致；偏紧时改为同字号的紧凑列表，仍放不下才退回原来的段落，卡片不滚动。换行不拆开词组、数字与单位或国名，「·」不出现在行首。只重排原有信息，不增加数据项。翻页时标题、页码和翻页控件的屏幕位置保持一致，支持连续点击同一处翻页。系列级资料单独标为「系列曾服役」。「史料 ↗」在新标签页打开所选条目的主要来源。年代筛选使用预览模型的外观年份。右上角关闭手册并返回原状态。
- 图鉴不显示评审状态或数值评分；国家下拉显示“俄罗斯”，筛选范围仍包含苏联与沙俄。类别以飞机、潜艇、航空母舰、巡洋舰、驱逐舰、战列舰平铺展示；移除巡逻护航艇、运输船类别及PT-109、约翰·布朗两个图鉴条目。
- 战役分页显示当前关卡（无尽中为当前波组）的十波名称、目标与出场阵容，包含护航、舰队补给与两场海上首领。页签支持左右键、Home／End，分页按钮可通过键盘和触摸操作。
- 手册使用双列操作说明与图例。操作说明、图例和附注从标题下方依序排列，组间距随窗口密度调整。矮窗口优先压缩留白，正文保持至少 14px，右上角关闭按钮和分页、筛选控件保持可见。可视区域极矮时，超出空间的图鉴内容可在卡片内独立滚动，翻页后从卡片顶部开始。

## 窗口与设备适配

- 根据可视窗口宽高布局，战场保持 480:760 的竖版比例。
- `game/viewport.ts` 跟踪 VisualViewport 的宽高与偏移，地址栏／底栏伸缩时按实际可见区域重新布局；不支持该 API 时使用窗口宽高，CSS 另提供 `dvh`／`vh` 回退。事件在动画帧内合并，原生双指缩放期间不重新排布。
- 手机战斗取可视安全区域内可容纳的最大完整 480:760 矩形，不裁切、拉伸或改变碰撞坐标。适用于窄窗口以及宽度不超过 1000px、高度不超过 600px 的触摸横屏；全屏为可选功能，普通浏览器内也自动最大化。
- 为刘海、底部手势条和横屏两侧保留安全区；暂停与投弹触摸目标至少 44×44px；窄战场缩小暂停键的可见底板，保留完整透明触摸范围，避免盖住首领栏。可视区域变化会清除旧拖动／按键输入，避免按旧缩放比例突然移动。
- 桌面采用任务说明、战场、机库三列；中等宽度保留战场和机库两列；手机机库使用战场与底部选择栏，战斗时只保留战场内 HUD 和操作。
- 页面不产生横向或纵向滚动。短窗口中的暂停、强化、结算内容应完整显示，关键按钮不得被裁切。
- 窗口改变大小后，绘制和输入坐标保持一致。
- 全屏时把画布与全部 HUD 放在同一竖版容器中居中，使用同一套可视区域和安全区尺寸，宽屏不把首领血条推入弹幕区域。浏览器不支持全屏时隐藏该按钮，不影响普通沉浸作战。
- 手机通过「暂停 → 设置图标」访问手册、声音和可用的全屏开关；从暂停菜单打开手册，关闭后仍停在暂停状态。桌面保留原有顶部工具。手册在可视安全区内居中，操作、战役与图鉴共用同一窗体尺寸、标题位置和内容间距。可视区域极矮时可滚动正文，关闭、切换和分页控件保持可见。图鉴预览区在各窗口尺寸下随卡片的可用高度收放，精灵保持原比例，预览与筛选区保持紧邻。窄屏图鉴将国家、服役时间、类别、页码和标题放在上方，预览与说明并排放在筛选区上方，多国服役信息在两者下方通栏显示，国名不拆行。极矮横屏将战役标题和目标并排，保留完整文字与主操作。
- 在全屏战场返回机库时先退出全屏，恢复可操作的顶部工具和战机选择，避免导航留在全屏元素之外。
- 提供可见的键盘焦点、按钮名称和 reduced-motion 支持。

## 本地存储

使用 `localStorage` 的 `sky-strike:` 命名空间保存最高分、出击次数、所选战机、游戏模式、战役解锁进度、战役选择、无尽起始章节、声音偏好和舰队外观。值以 `{ version: 1, value }` 写入，兼容旧版未包装的有效数据；旧难度记录会被忽略，首次使用新版本时默认进入战役。非法存档字段恢复默认值。解锁和选择跨刷新保留，正在进行的战斗随刷新结束。存储不可用时仍可游玩。

战役通关记录与选择按关卡 ID 保存。旧版八关的已通关记录会映射到对应战役，供重玩。旧版选中的战役若需要重新解锁，机库会选中时间线中第一个尚未通关的战役。继续通关时会跳过已有通关记录的战役。

## 历史舰库

- 「图鉴」的水面舰艇展示八国的126个条目，含二战至现代美国82个舰级分组。可按国家、四种水面舰种和外观年代筛选，直接查看条目或循环翻页。每条记录显示国别、服役时间、舰级或舰种、结构特征和史料链接。
- 图鉴使用本地二维画布预览，查看条目时加载 PNG 精灵。快速翻页时丢弃迟到请求，加载失败后可重新打开该条目。
- 图鉴供浏览。战斗读取已有的本机舰船外观记录，非法或过期记录回退到对应默认舰。舰船与沉没残骸保留生成时的外观。
- 参考舰不是额外战斗数值或新技能；默认水面原型为PT-109、弗莱彻、克利夫兰、大和、赤城、约翰·布朗，开场友军航母参考企业CV-6。详细名单与来源见[历史舰库](historical-fleet.md)。

## 声音与运行资源

- Web Audio 实时生成射击、爆炸、受击、航弹、对舰命中、部件破坏、主炮演出、升级、出击、结算和补给音效。
- 默认静音，玩家操作后可以开启声音。
- 字体、图标和 离线生成的 PNG 精灵均随项目提供，游戏运行不依赖外部资源服务。
- 使用 TypeScript、Vite 和 Phaser 4.2.1 开发；本地通过 `npm run dev` 启动，构建后的 `dist/` 可部署至静态网站服务。


## 移动浏览器验证

`npm run test:e2e` 默认优先使用本机 Chrome，包含真实触摸、最大画面尺寸、工具栏导致的可视区域变化、安全区、横竖屏、全屏、暂停设置和像素辨识回归。可通过下列命令补充 WebKit 检查：

```sh
npx playwright install webkit
PLAYWRIGHT_BROWSER=webkit npm run test:e2e -- tests/browser/mobile-layout.spec.ts tests/browser/layout.spec.ts tests/browser/visual.spec.ts
```

可视区域与安全区变化由测试注入确定尺寸；WebKit 验证浏览器引擎兼容性，不能替代实体 iPhone 对宿主浏览器工具栏的检查。CDP 的真实触摸重绘用例只在 Chrome 中运行。

## Phaser 二维运行时

Phaser 场景负责帧循环、键盘／鼠标／触摸、资源加载、粒子和补间。战斗规则仍为独立 TypeScript 模拟，保持原碰撞半径、伤害、计时与固定随机种子通关验证。启动加载 26 项基础精灵及本机已选舰，其余精灵按需加载；基础加载失败显示“重新加载”，图鉴失败可单独重试。机库和图鉴使用 Canvas 2D 绘制已加载精灵，不创建额外 WebGL 上下文。生产包不含 Three.js 或 GLB。
