# 功能清单

## 机库与界面

- 机库提供三架战机选择、3D 模型预览和火力／机动／装甲展示。
- 桌面机库提供标准与休闲模式选择，展示任务说明、最高分、出击次数和操作提示。
- 手机使用紧凑的战机选择栏，把可视空间优先留给竖版战场。
- 开战后禁止切换战机或难度。可通过暂停菜单重新出击、返回机库。
- 战斗 HUD 显示积分、波次、装甲、等级、能量进度、当前机炮和剩余炸弹。
- 战斗计分栏背景向下渐隐，波次提示采用两侧渐隐的半透明横幅，保证窗口缩小后顶部敌弹和玩家战机仍可见。
- 首领战显示首领名称、装甲条和剩余百分比。
- 波次、航区切换、补给与首领击破有短暂提示；强化面板展示三个选项、效果与叠加等级。
- 桌面侧栏显示本局已获得的强化。
- 机库和手册提供战场识别图例；战斗中提示“红弹躲避 · 补给拾取”。道具通过颜色、外框和中心符号共同区分，避免和敌弹混淆。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD、方向键、按住鼠标拖动 | 在战场按住拖动 |
| 自动射击 | 战斗期间自动执行 | 战斗期间自动执行 |
| 高爆航弹 | 空格、B、右下角按钮 | 右下角按钮 |
| 暂停／继续 | P、Esc、暂停按钮 | 暂停按钮／继续作战 |
| 强化选择 | 点击卡片、数字键 1／2／3 | 点击卡片 |
| 声音开关 | M、顶部声音按钮 | 顶部声音按钮 |
| 全屏 | 顶部全屏按钮，需浏览器支持 | 顶部全屏按钮，需浏览器支持 |

拖动采用相对位移，按下时不会把战机瞬移到指针位置。对角线键盘移动会归一化，保持与单方向相同的速度。

## 暂停与作战手册

- 手动暂停时冻结战斗，支持继续、重开、返回机库。
- 页面进入后台或窗口失焦时自动暂停，并清除持续按键和拖动状态。
- 升级三选一时自动冻结战斗，完成选择后继续，并给予短暂保护。
- 打开作战手册会暂停正在进行的战斗；关闭手册后恢复该场战斗。
- 手册介绍电脑／手机操作、随机成长、目标、受击判定与本地纪录。
- 手册使用双列操作说明与紧凑图例，矮窗口隐藏重复导语；关闭按钮与“明白，准备出击”始终完整可见，手册自身也不产生滚动。

## 窗口与设备适配

- 根据可视窗口宽高布局，战场保持 480:760 的竖版比例。
- 使用动态视口高度适应手机浏览器地址栏变化。
- 桌面采用任务说明、战场、机库三列；中等宽度保留战场和机库两列；手机使用战场与底部选择栏。
- 页面不产生横向或纵向滚动。短窗口中的暂停、强化、结算内容应完整显示，关键按钮不得被裁切。
- 窗口改变大小后，绘制和输入坐标保持一致。
- 全屏时把画布与全部 HUD 放在同一竖版容器中居中，按实际画布宽度缩放，宽屏不把首领血条推入弹幕区域。
- 提供可见的键盘焦点、按钮名称和 reduced-motion 支持。

## 本地存储

使用 `localStorage` 的 `sky-strike:` 命名空间保存：最高分、完成的出击次数、所选战机、难度和声音偏好。当前战斗进度不跨刷新保存。存储不可用时游戏仍可运行。

## 声音与运行资源

- Web Audio 实时生成射击、爆炸、受击、炸弹、升级、出击、结算和补给音效。
- 默认静音，玩家操作后可以开启声音。
- 字体、图标和 Blender 导出的 GLB 模型均随项目提供，游戏运行不依赖外部资源服务。
- 使用 TypeScript、Vite 和 Three.js 开发；本地通过 `npm run dev` 启动，构建后的 `dist/` 可部署至静态网站服务。
