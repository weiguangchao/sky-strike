# 全球服役目录补录

本目录记录后续收录的证据和待核实事项，不是已建模清单，也不是完整的全球服役名录。手册当前仍是原有148条舰艇外观及首批20个飞机／潜艇模型；这里的研究记录不计入模型数或通过数。

## 飞机资料

[aircraft-research.json](aircraft-research.json) 当前有11项后续研究记录：10项找到实际使用的军方／博物馆依据，HT-2目前仅核实向军方交付。每条保留来源、所支持的事实、改型边界及未解决问题。`evidenceYear`是资料记录的使用事件年份，不能自动当作首飞年、入役年或所选模型的外形年份。

记录覆盖日间轰炸、侦察、重型轰炸、运输、海上巡逻、两栖机、军用滑翔机、基础／喷气教练机、轻型攻击及加油机。型号为DH-4美制Liberty构型、Breguet XIV B2、B-17G、C-47A、PBY-5A、CG-4A、C-130H、双座MB.326、A-29、HT-2及KC-135R。

这些记录的`geometry`均为空，评分列表为空。完成本型外形资料、Blender源文件、实际GLB、资源和浏览器验证后，才能加入运行时手册。加入后仍须取得同轮同版本的两名独立GPT Sol逐项各至少9.8分，研究资料不能替代验收。

需保留的资料边界包括：

- C-47网页的实物是D型，展示涂装代表A型；两者不可混同。
- MB.326官方网页同时讨论双座教练型和单座K型，末尾技术表不能直接套入双座型。
- C-130官方页部分英制尺寸与括号公制值换算不一致，尚未据此设定几何。
- HT-2的1951年是首飞时间，现有资料不支持将其写成入役年份。
- A-29尚未选定A型单座或B型双座；与EMB-312另记。
- 许可生产、运营国、转让及改装须与设计来源国家分开，不能只因换国或改名重复宣称新增型号。

## 旧舰库身份核对

[surface-class-audit.json](surface-class-audit.json)从现有定义提取148条外观：82条具有显式`classId`分组，66条仍需补充规范舰级身份。82是现有分组字段数量，其中可能包含亚级或改装分组，不能直接称为82个独立舰级。

`sharedSourceCandidates`仅列出共享资料页的研究线索，`verifiedSameClass`仍为`false`。例如衣阿华／密苏里、大和／武藏等条目需要在确认舰级关系后归于同一型号的不同外观；共享URL本身不是身份验证。规范化时保留既有战场外观选择及其模型，不能通过删除姊妹舰来冒充完成旧模型验收。旧148个几何均仍需独立双Sol评审。

## 扩充与版本

下一批模型使用独立的输入、生成脚本、`.blend`及清单，避免追加新型号时无意重建已验收模型。现有模型的GLB、完整定义、所属源库或生成脚本一旦变化，必须使旧评分失效；不能把旧票复制到新指纹。

全球名录仍须按国家、年代和任务类别持续核对。未核实的型号不填入伪造的尺寸或服役年份，也不预设全球型号总数。
