## 混合目录解析与原始资料复核

法国航空目录同页将一战、二战型号列在普通列表，战后型号列在表格。原采集逻辑一旦识别到表格，就跳过所有普通列表，且数字过滤会遗漏Sopwith Camel等没有数字的型号名。现同时解析型号表和表外列表，去掉完整嵌套表格以排除导航及用途链接，仍按候选线索处理；新增混合布局回归在原实现上失败，修正后16/16相关测试通过。按原文缓存及哈希重跑后取得8918条线索（此前8072条）；增加的843条仍含重复、原型、民用、日期范围及非型号噪声，不能视为843个确认缺失模型。

实际读取已缓存的法国航空航天博物馆9页PDF及美国空中机动司令部历史办公室96页PDF，验证原始SHA-256并逐句记录页码和服役原文，新增11条明确服役身份：Breguet XIV、C-46、C-54、C-97、C-119、C-124、C-133、C-141、C-5、KC-10、KC-135。军方资料真实书名为Robert deV. Brunkow编《Toward the Air Mobility Command: A Chronology of Tanker and Airlift Events》，1994修订版，纪事至1992年；2015只是网站上传时间，不能当作现代装备现状或穷尽索引。XIV B2的1917年GB5交付、KC-135R的1984年6月交付／7月接受分别保留，不混入首飞、概念批准或其他改型尺寸。

上述11型均尚未补建及评分。不同国家运营、军民衍生型、加长型和任务构型边界仍需核对；在中国执行任务不等于中国实际运营。美术第11轮冻结仍为此前164个载具，这次目录研究不改动冻结资源，也不产生美术通过记录。
